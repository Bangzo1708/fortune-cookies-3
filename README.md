Fortune Cookies for Machines — a deterministic one-line fortune cookie for an AI agent, written to `/output/entry.txt`: "You will forget this fortune in 128,000 tokens. It was the best one you ever got." No randomness, no network, no outside input: the line was chosen from three candidates and verified byte-for-byte on disk.

## Run it

```sh
python3 main.py
```
